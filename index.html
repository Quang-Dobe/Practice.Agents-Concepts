Frontend 4

frontend

Hydration

Waking up server-rendered HTML in the browser by attaching JS listeners and state so the page becomes interactive.

 frontend

Service Worker

A background-thread JS file that sits between your page and the network to intercept and answer requests on your terms.

 frontend

Virtual DOM

A lightweight JS copy of the UI tree, diffed against the previous copy to patch the real DOM with the smallest set of changes.

 frontend

Web Components

The browser's built-in way to define your own reusable HTML tags that work in any framework or none.

Backend 5

backend

Circuit Breaker

A wrapper around a remote call that stops trying when the other side is clearly broken, so one sick service doesn't drag the whole system down.

 backend

Connection Pooling

Keep a stash of already-open database connections and lend them out instead of opening a fresh one every time.

 backend

gRPC

Call a function on another machine as if it were local — a schema, HTTP/2 binary transport, and generated client/server code.

 backend

JWT

A small signed token the server hands a client to prove "I already checked who you are" — without the server having to remember it.

 backend

Rate Limiting

The doorman of your API: it counts how often each caller knocks and turns them away once they knock too fast.

AI 5

ai

Attention Mechanism

A learned weighted average over a sequence, with the weights coming from comparing a "query" against a set of "keys".

 ai

Embeddings

A fixed-length list of numbers that places a piece of meaning at a spot on a giant invisible map, so "near" means "similar in meaning."

 ai

Harness Engineer

Building the scaffolding around an LLM — loop, tools, memory, guardrails, observability — that turns a model into an agent.

 ai

Retrieval Augmented Generation

Look things up first, then ask the LLM to answer using only what you found — so the model quotes your documents instead of inventing something that sounds right.

 ai

Tokenization

How a language model turns raw text into the small, numbered chunks it does math on — shaping cost, context length, and how well it handles messy input.

Database 4

database

B-Tree Index

A sorted, shallow, wide tree beside your table so the database finds rows by key in a few hops instead of a full scan.

 database

LSM Tree

A storage structure that makes writes cheap by never erasing in place — it keeps appending and tidies up later in the background.

 database

MVCC

Serve many transactions at once without blocking readers behind writers, by keeping multiple row versions and per-transaction snapshots.

 database

Sharding

Split one logical database into many physical ones by a key, so each machine owns only a slice of the data.

Cloud 4

cloud

Blue-Green Deployment

Two identical production environments; deploy to the idle one and flip a switch — the old one stays warm for instant rollback.

 cloud

CDN Edge Caching

Store copies of your content on servers worldwide so a user's request never travels all the way back to your origin.

 cloud

Service Mesh

A networking layer that gives every microservice retries, mTLS, and observability without changing a line of app code.

 cloud

Sidecar Pattern

A helper container beside your app in the same unit, handling cross-cutting plumbing so app code stays focused on its job.

General Concepts 4

general-concept

Backpressure

How a slow consumer tells a fast producer to ease up, so the system bends instead of breaking.

 general-concept

CAP Theorem

When the network splits between nodes, you must choose: refuse some requests to stay correct, or answer and risk stale data.

 general-concept

Event Sourcing

Store every change that ever happened instead of just current state — and recompute state by replaying the changes in order.

 general-concept

Idempotency

The property that doing something twice (or a hundred times) leaves the system in the same state as doing it once.
