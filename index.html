Hydration

Waking up server-rendered HTML in the browser by attaching JS listeners and state so the page becomes interactive.

 frontend

Service Worker

A background-thread JS file that sits between your page and the network to intercept and answer requests.

 frontend

Virtual DOM

A lightweight JS copy of the UI tree, diffed against the previous copy to patch the real DOM minimally.

 frontend

Web Components

The browser's built-in way to define your own reusable HTML tags that work in any framework or none.

Backend 5

backend

Circuit Breaker

Stops calling a broken remote service so one sick dependency doesn't drag the whole system down.

 backend

Connection Pooling

Keep a stash of already-open database connections and lend them out instead of opening a fresh one each time.

 backend

gRPC

Call a function on another machine as if it were local — a schema, HTTP/2 binary transport, generated code.

 backend

JWT

A small signed token the server hands a client to prove "I already checked who you are" — no server memory needed.

 backend

Rate Limiting

The doorman of your API: it counts how often each caller knocks and turns them away when they knock too fast.

A learned weighted average over a sequence, with weights from comparing a "query" against a set of "keys".

 ai

Embeddings

Numbers that place meaning on a giant invisible map, so "near each other" means "similar in meaning".

 ai

Harness Engineer

Database 4

database

B-Tree Index

A sorted, shallow, wide tree beside your table so the DB finds rows by key in a few hops, not a full scan.

 database

LSM Tree

Cheap writes by never erasing in place — it keeps appending and tidies up later in the background.

 database

MVCC

Serve many transactions at once without blocking readers behind writers, by keeping multiple row versions.

 database

Sharding

Split one logical database into many physical ones by a key, so each machine owns only a slice of the data.

Cloud 4

cloud

Blue-Green Deployment

Two identical production environments; deploy to the idle one and flip a switch — the old one stays warm.

 cloud

CDN Edge Caching

Store copies of your content on servers worldwide so a request never travels all the way to your origin.

 cloud

Service Mesh

A networking layer that gives every microservice retries, mTLS, and observability without touching app code.

 cloud

Sidecar Pattern

A helper container beside your app in the same unit, handling cross-cutting plumbing so app code stays focused.

General Concepts 4

general-concept

Backpressure

How a slow consumer tells a fast producer to ease up, so the system bends instead of breaking.

 general-concept

CAP Theorem

When the network splits, you must choose: refuse some requests to stay correct, or answer and risk stale data.

 general-concept

Event Sourcing

Store every change that ever happened instead of just current state — recompute state by replaying them.

 general-concept

Idempotency

The property that doing something twice (or a hundred times) leaves the system exactly as doing it once.
