Two-Phase Commit

A protocol that lets one transaction span several databases and makes them all commit or all roll back, by first asking everyone “can you commit?” and only then telling everyone “commit.”

2
round trips per commit: prepare, then decide
2n + 1
forced disk writes with n participants
1991
X/Open standardizes the XA interface
0
Postgres default max_prepared_transactions (2PC off)
