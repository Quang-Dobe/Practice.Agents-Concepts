LSM Tree

A storage structure that makes writes cheap by never erasing in place — it keeps appending and tidies up later in the background.

1996
the LSM-tree paper (O'Neil et al.)
10 bits/key
typical Bloom filter size — ~1% false positives
>10x
typical write amplification under leveled compaction
10 days
Cassandra's default tombstone grace period
