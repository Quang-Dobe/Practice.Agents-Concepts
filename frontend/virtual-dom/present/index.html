Virtual DOM

A lightweight JS copy of the UI tree, diffed against the previous copy to patch the real DOM with the smallest set of changes.

2013
React introduces the Virtual DOM publicly
O(n)
diff cost, vs the textbook O(n³) tree-edit distance
~40 kB
React + ReactDOM gzipped
3 kB
Preact gzipped — smallest mainstream VDOM
